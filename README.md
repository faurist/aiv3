# Pista AI V3 – személyes ügynök

A V3 tartalmazza:
- Gemini alapú ügynök
- webes keresés Tavilyjal
- tartós egyszerű memória
- szöveges dokumentumok feltöltése és kontextusként használata
- PWA telepíthető mobilfelület
- memória törlése

A dokumentumfeltöltés ebben a verzióban TXT/MD/CSV/JSON/HTML szöveges fájlokra van optimalizálva. PDF-hez következő verzióban érdemes valódi PDF-parser/RAG réteget hozzáadni.

Render:
Build: npm install
Start: npm start

Environment:
GEMINI_API_KEY=...
TAVILY_API_KEY=...
